# 任务效用候选：独立测速组件与真实CPU路径

新增单条件测速入口、来源／前缀核对与B1/B4独立计时组件，17项人工检查通过。逐项验证真实批量大小、预热状态、单模型限制、全部七段原文件绑定、输入／输出变化即停和实际延迟统计。首次人工fixture仅一个原始锚点，触发旧NMS的标量mask形状错误；改为两个锚点但一个候选框，原NMS、模型及真实23625锚点路径不变。失败源码、日志和退出码完整保留。

原研究写26项同B1路径，但其中历史原RGB明确来自B4，不能与新鲜B1或检测包重放混同。在正式TaskUtility拟合前另行冻结执行澄清：25项真实B1路径加1项真实四观测B4原RGB参照；26项准确率配方、主方法、预算与Dev选择规则不变。每项都先独立核对，再计时七段各32帧，前8帧预热、后24帧计时，共168帧；B4记录42个批次延迟，不能把摊销每图成本称作单帧延迟。

正式入口必须已登记完整流程、前序真正导出退出、完整Test来源和原Dev冻结后才能调用CUDA。B4另用原FP16／原数值策略核对原B4检测包和逐视频MOT；不能替换成B1、四份当前帧复制或放宽一致性。历史四worker loader与全Test吞吐不冒充本次同步前缀成本。读取／解码／所需模态字节hash、预处理＋NN＋NMS＋回主存、ByteTrack的墙时分开记录，包含少量clock／同步开销；来源核对、输出摘要、资源核对在计时外。验证可能预热OS页缓存，不声称冷盘或性能方差。

实际CPU检查只使用Train BT-003第1–8帧、一个域：独立原float64归一化再量化输入，与lookup输入逐值精确；冻结RGB模型实际完成六次B4前向、24次帧访问，参考／验证／计时三次路径的原始head、NMS包与字面MOT均一致。原RGB权重／BN／梯度不变，前向诊断hook移除，无优化更新、IR字节读取、TaskUtility快照加载或新Dev/Test。实际CPU总用时362.954秒，峰值RSS2.557GiB。CPU为FP32恢复的原FP16权重，并含输入／输出hash hook，八帧／四帧预热仅为工程范围，不能作为原FP16 GPU/B4一致性、正式方法FPS、融合贡献或完整研究执行资格。

实际测速CLI预检因完整TaskUtility登记缺失在加载模型或调用CUDA前停止；F4前序仍未释放。新的正式GPU工作为0，完整控制器、总结果导出及集成检查仍待补齐，原CPU数值异常原因也未解决。本轮不增加独立创新计数；主结构方案13项完整Test继续在4／5卡执行。固定新版IR、seed0、最多两卡、64GiB工作盘、40GiB独立空闲限制保持；代码与轻量结果入Git，Goal active。

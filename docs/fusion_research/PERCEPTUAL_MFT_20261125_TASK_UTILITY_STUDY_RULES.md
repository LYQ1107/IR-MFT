# 任务监督四组合：纯Dev规则组件

八项人工曲线检查通过，未读取真实Dev/Test、图像或权重，不分配GPU，
不能构成正式研究登记、实际模型选择或准确率证据。已验证独立贡献0。

四种监督组合是无新增监督、仅前景、仅效用、前景＋效用；每种均有
重复RGB、灰度、新版IR，共12个正常条件。推理结构和容量保持相同。
新增规则要求每个已执行完整Train epoch对应两个Dev视频全部4834帧，
四个IR条件的每个快照均有完整缺失与真实图像roll干预；缺行、重复行、
Test、非seed0、未知条件、无效指标均拒绝。

预算仍拟采用至少6遍完整27251帧Train、统一阶段6／9／12和固定12遍
学习率周期。阶段6或9比较所有12项当前最佳Dev HOTA与前三遍前缀最佳，
任一项改善严格超过0.2点则统一延长三遍；恰好0.2不延长，12遍必停。
阈值比较使用十进制避免0.2边界的二进制舍入误触发；没有新增种子。

选择仅用完整正常Dev的HOTA、AssA、IDF1，依次打破平局，再取更早epoch
和预设组合顺序。保留12个正常条件各自的Dev最佳；主IR由四个IR最佳
选择。同组合RGB／灰度及跨组合最强RGB／灰度均按Dev保存，不按Test选。
即使所有IR都低于RGB，也必须保留并评估所有正式模型。

纯规则预期生成26项完整七段Test配方：12个正常模型、四个IR各自的
缺失／roll共8项、主IR三个推理门控去除、一个推理时固定原RGB坐标
干预、原RGB规范／新鲜B1两个参照。门控／坐标项是同一已学模型的
推理干预，不能称为重新训练的去除实验或独立架构。
这些是待冻结的配方，当前实际新Test执行数为0。

八项检查覆盖Test／截短／种子与异常指标拒绝、12条完整曲线及重复
拒绝、每个IR快照的输入干预、0.2阈值及单个RGB改善触发共同延长、
未来Dev不改变较早预算及12遍停止、平局和干预不能选择正常模型、
全部IR较差仍保留完整Test与强对照、篡改选择或截短模型集合拒绝。

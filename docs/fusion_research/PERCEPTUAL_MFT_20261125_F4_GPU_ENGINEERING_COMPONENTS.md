# F4 GPU 工程入口与独立比较器：组件检查通过，真实 GPU 资格未建立

本轮没有新 Dev/Test HOTA、学习 IR 融合转移或创新贡献。原两卡训练和所有
既有队列保持不变，Goal active。完整调度/最终导出仍缺，尚无完整 F4 登记。

新增真实 GPU 工程入口。它要求完整登记、原空间控制器及全部子进程退出、
原父模型完成完整 Dev 强对照；两套 RGB/融合模型必须先严格 CPU 加载，
再使用物理4/5卡，核对实际 CUDA 张量。两段 Dev 各32帧，全正常记忆配置
加固定主 IR 的缺失/四分之一图像错位，只做工程比较，不选择模型或评估。
编译器内核缓存须位于有64GiB上限的工作目录内，避免写满用户主目录。

比较器逐帧核对独立 NN 输出的实际检测包、原 ByteTrack 的零路径数值
状态/轨迹，以及非零路径 KF/ID/保留记忆与独立重放状态。重放使用本次
实际捕获的 ROI 包，**不是第二种 ROI 实现**；坐标数学另由既有已知平面
检查建立。零记忆还须匹配原完整 Dev 轨迹文件的前缀；原生家族不补造
未保存的检测前缀，空间家族额外要求其已有图像前缀。GPU 资格还要求真实
主 IR 的有效且不同于 RGB 的融合 ROI、保留融合记忆及正关联惩罚均被执行。
GPU 检查不是完整 Dev/Test，也不提供共享多配置 FPS 或准确率。

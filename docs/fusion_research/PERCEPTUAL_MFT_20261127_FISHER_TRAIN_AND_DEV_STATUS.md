# 新版伪红外：Train 身份投影与固定 Dev 方案

最新用户目标是相对原始直接 RGB-only YOLOX-X+ByteTrack 至少提升5个绝对 HOTA 点，进一步争取10点。当前完整 Test 为29.799525，原始 baseline29.528971，提升0.270555，目标未达到。暂缓额外 RGB 网络结构和多种子工作，保留全部历史结果。

已在 CPU 完成经典正则 Fisher 身份投影。复用六个 Train 视频各192帧的只读 RGB/11月新版 DiffV2IR P3缓存，共1152帧、17270个真实 GT ROI。完整 Train 有98组视频内身份；采样中出现97组，其中3组仅有1、2、1条观测，缺少足够时间留出证据，排除后用94组、17266条观测拟合640至64维投影。这里的身份是视频内标签，不声称是98个不同的物理个体。未重训神经网络，未读取 Dev/Test GT进行拟合。

每个视频、每个身份等权；类间散度在视频内部中心化，投影使用类内协方差正则白化。每条候选分别归一化 RGB/IR向量后配对；推理不输入身份标签或视频类别。Fisher/LDA、EMA及余弦相似度是经典组件，目前不宣称它们本身是独立创新。

诊断投影只拟合每个合格身份前70%的时间观测，后30%作为检索查询；最终部署投影使用全部合格 Train 观测。这是同一批 Train 身份的时间留出检索，不是未见身份泛化、跟踪 HOTA 或红外独立贡献的证据。原始 IR与直接拼接均弱于原始 RGB，必须保留这一负结果。投影相对原始RGB的约6.23个百分点检索提高不能写成 HOTA提高。

固定视觉父模型仍为 `NP_temporal_ir_e06`，所有方法读取相同新版伪红外。预注册完整 Dev 仅五项：零权重原始关联；Fisher权重0.25/0.50与身份保留25/250帧的四种组合。每轨迹保留可靠当前观测的归一化 EMA；外观在固定运动约束内参与原始 ByteTrack 的首轮匹配。所有帧按因果顺序输出，序列之间重置身份和记忆，不回改历史输出。新统计区分实际浮点代价变化与实际首轮匹配变化。

物理 GPU4/5 的工程子进程均实际退出0：六个真实 Train 视频首帧的 RGB/IR P3 与旧缓存逐字节相同，零权重检测/MOT精确复现，序列切换后复现、跳帧拒绝与权重不变检查通过。当前两卡正在运行完整 Dev4834帧。以HOTA、AssA、IDF1及较短记忆/较小权重的固定规则选择；只有比相同视觉父模型正向提升才冻结一项方法进入完整 Test15985帧，不按 Test 改参数。注册与当前进程快照见同名 JSON；运行中不代表已完成。

首次 CPU 启动因本地依赖路径未设置在导入前失败；第二次因实际采样出现稀疏身份而停止。两次原始退出1、旧源文件与注册均保留。新增 Train-only稀疏标签规则后，第三次实际退出0。没有安装新包或丢弃失败记录。

# 固定新版伪红外：保留主关联的因果身份续接

当前完整Test仍为29.799525，相对原始RGB-only YOLOX-X+ByteTrack29.528971仅+0.270555，未达到至少+5，进一步+10的目标。此前Fisher混合主关联的四组完整Dev均负，原件保留，不追加无收益的Test。

本轮保持同一YOLOX-X、冻结的`NP_temporal_ir_e06`检测输出及固定11月DiffV2IR图像。显式增加已完成seed0固定36轮训练的两路同构ResNet50身份编码器，读取RGB与新IR的128×256候选裁剪；这是附加身份模块，不是替换比较用的RGB baseline。使用FP32归一化BN-neck512维特征，避免旧pre-neck余弦几乎恒定的尺度问题。本轮不重训网络，不选择新检查点或种子；既有训练预算与额外推理成本必须如实报告。

只在旧内部轨迹彻底退出原ByteTrack的tracked/lost匹配池、且新轨迹的身份尚未首次发布时，尝试输出旧身份。RGB历史模板、当前两次可靠观察、运动可达性、尺寸及双向唯一性间隔全部过关，IR条件再要求红外一致。已经发布的身份与历史输出均不回改；25帧保留时长的各条件只允许ID不同，输出框、分数、顺序必须与零路径相同。250帧保留本身可能改变原关联，单独报告。

五项固定Dev：原25帧零路径；只延长至250帧；RGB身份续接；RGB+IR身份续接；250帧保留加RGB+IR更长间隔续接。按完整Dev HOTA、AssA、IDF1及预定简单性顺序选择，只有相对相同零路径正向才进入冻结的完整七段Test。没有按视频设置不同规则，不按Test改选。

阈值只读取既有11967条Train描述符：RGB余弦阈值0.5、IR为0.301876、双向RGB间隔0.1；模板更新要求分数>0.6、最大重叠<=0.5，旧模板至少3次、新模板至少2次可靠观测。几何可达上界使用既有Train-only速度0.131374个身体对角线/帧。这些描述符编码器见过该批Train身份，阈值统计偏乐观，不能当成Dev或Test识别精度。

R1源代码登记后、任何GPU运行前发现了原ByteTrack“一帧仍可匹配”的移除边界；人工夹具已复现R1在第30帧重复输出身份的断言失败。R2保留原代码与登记，等待内部轨迹真正离开匹配池，并确保阈值以下的近似竞争者仍参与唯一性间隔判断。R2六项CPU回归实际通过，两张物理GPU各12帧真实工程均实际退出0：零MOT精确复现、缓存后6帧描述符反号不影响前6帧重放输出、编码器/检测器权重与BN不变，每卡、每模态各一个Train参考裁剪的身份向量与原FP32缓存最大绝对误差分别约1.65e-7、5.33e-7。R1未启动GPU，不伪称已有正式失败精度。

当前GPU4/5正各执行一段完整Dev的候选/描述符提取，后续五项关联在CPU复用同一小型缓存。全部Dev加可能的Test未压缩载荷预计0.898842GiB，不保存图像或整帧FPN；工作目录约60.27GiB、上限64GiB，独立空闲远大于40GiB。不会上传NPZ、权重、MOT、图像。初次Train阈值CPU快照的argv为空，原记录保留，实际wait退出0及来源SHA完整；没有声称取得那次非空live argv。R2复用相同阈值字节而非重复拟合。

# 已训练融合P3的身份区分诊断：效果很小，不能计作身份创新

本轮只使用六段Train中原先已固定的72帧、1079个GT框观测。六组已完成拟合各取第24／48／72宏循环快照，共18份真实权重；没有新增训练或随机种子。当前融合输出、结构错位参考、两者池化后的差值proxy，以及原RGB／灰度／IR特征全部保留；没有根据结果删掉模型或序列。

以过去采样帧的GT鱼框特征作为gallery，当前帧GT鱼框作为query，仅对gallery中已有的身份计分并报告其余数量。GT只用于Train诊断的ROI坐标及检索标签，没有输入融合网络。无效／零向量计作未匹配，而非从准确率分母删除。全部查询按观测次数汇总，不对六段百分比简单平均。

“间隔1／2／4”指原均匀采样列表的位置，不是相隔1／2／4个视频帧。真实帧间隔范围见下表；这些往往是很长的间隔，且训练身份已经被模型见过。此处不是完整在线MOT，也不是身份未见域泛化。

主表比较同一第24宏循环（一遍完整Train）的全S+C+R、相同145600个可训练参数和同一GT查询集。IR比RGB仅多5／1／0次正确匹配，对灰度则多1／4／少2次。不能据此说得到了稳定而明显的独立身份收益；表中是检索准确率，不是HOTA。全部18个快照、各域、current／null／差值proxy数据见[完整记录](PERCEPTUAL_MFT_20261125_TRAIN_FUSED_ROI_IDENTITY.json)及[六段结果](perceptual_20261125_train_fused_roi_identity)。

IR第24宏循环的池化特征相对RGB变化幅度平均为RGB范数的4.135%，current与null差异为4.017%。融合不是完全未激活，但变化没有转化为大幅身份区分改善。延长至第二／三遍时变化幅度增大，检索结果没有整体单调提高，全部曲线保留。

IR池化current−null差值proxy的三档检索准确率分别10.591%、7.407%、7.193%，也没有稳定超过当前融合向量。这个proxy未训练，C真实操作是在语义logit层作有界相减，因此不能把此proxy负结果解释为整个C模块失败，也不能把C的Dev／Test正消融自动解释成新的身份表示能力。

几何参照只使用前后GT框中心的尺度归一距离，没有Kalman速度预测；它不是项目baseline或ByteTrack。在三档间隔的正确率为19.654%、14.478%、9.732%。其分数是负中心距离平方，外观分数是余弦值，二者margin幅度不作跨单位比较。当前查询多次重复同一鱼、同一视频，计数不是独立样本，不据此作显著性或泛化声明。

证据支持继续检验融合特征是否需要与身份任务更直接的约束，以及池化是否保留了有用的局部信息。目前不把简单P3平均池化或未训练差值proxy列为已验证创新。后续已登记的质量、空间、因果时序与F4实验仍须真实完成；这些不同家族不能被本诊断替代或直接排除。前景／任务效用监督同样尚待正式拟合。

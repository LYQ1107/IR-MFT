# 训练前补齐逐层门控统计

2026-11-24。核对原任务书时发现，原生金字塔首版完整控制器尚未导出逐层gate统计。首次队列仍在CPU等待，既无子进程，也无GPU工程或正式训练目录；核实真实PID、工作目录及状态后，只终止该等待进程并归档第一版元数据。原GPU4/5训练和其他补测没有停止，Goal保持active。

第二版加入`NativeGateObserver`，在前向完成后只读输出与输入，不保留图像/特征Tensor，不改变模块定义、参数、损失、预算、种子或选择规则。每个正式非基线条件、每段Dev/Test视频、P3/P4/P5分别记录：

- quality gate的样本数、均值、标准差、最小值、最大值。
- 时间增益和内部协方差的相同统计，按有效特征位置计数；质量模式没有协方差时保留空统计。
- 经过实际输出dtype转换后的特征修正RMS、相对RGB特征RMS、非零修正位置比例。
- 教师高置信位置数与其中改变的特征位置数，只描述特征保护，不保证邻域检测头输出不变。
- 当前输入可用/缺失帧数。缺失帧不虚构gate=0，完全无效画布也不制造有效修正样本。

观察器不参与训练、模型选择或融合计算。完整视频共享生产包含记录开销，仍不能作为单模型FPS；单模型成本程序不挂此观察器。正值协方差是内部置信参数，不是物理红外传感器噪声标定，gate激活也不是精度贡献证明。

三项新增检查验证：挂观察器前后输出精确一致且可测到非零修正；成熟时间状态缺失时清空并精确回退、没有虚构样本；无效画布不计入特征变化。随后整套**50项CPU检查通过，100个源码/配置版本保持一致**。使用第二版代码重新回放全部4,834帧规范RGB Dev，39摘要及整个官方276列CSV再次精确一致。GPU实图检查仍未执行，将在现有作业释放两卡后先验证GPU统计和完整源/零分支/缺失回退，再进入正式训练。

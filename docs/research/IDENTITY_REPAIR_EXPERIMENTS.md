Physical labels and same-frame hard neighbors exist only in offline training artifacts. Reference identity is established by at least3 known earliest accepted observations with>=.6consensus, not one immutable first token. Clean counterpart uses physical same-ID past features; actual counterpart keeps the exact anchor/recent8 state. Unknown labels receive no wrong-token supervision. The fit pool contains65naturally incorrect first-anchor queries (8BT-001,38BT-003,19MSK-002); SN-015calibration has0such raw queries. First-anchor replacement is explicitly included as a nearby-other-fish stress perturbation before fitting; artificial first-anchor recovery must be reported separately from natural cases, not substituted for them.

The first frozen trial is intentionally small:866allocated parameters, including769token reliability decision parameters and97confidence diagnostic parameters. Observable evidence consists of past feature consistency, min/max/mean cosine, recent/initial similarity, relative token position and frozen age/gap channels. Soft weights restore the read prototype without refusing all new writes, changing motion, or using GT. First token receives no privileged fixed truth. This first read-state baseline is not yet the complete multi-prototype RIS promised by the research task. Confidence is a diagnostic, never a GT-aware online gate.

Two matched866parameter objectives use identical eight epochs, fit queries, video/identity uniform sampling, AMP, seeds, perturbations and architecture: associationCE alone versus associationCE + balanced known-token reliabilityBCE + confidenceBCE. Near hard negatives come from actual different fish in the SAME past frame, within two body diagonals; first token or contiguous suffix can be replaced. Contiguous missing observations leave at least1past token. No random image/noise-only source is used. Ordinary/frozen models and memory controls remain necessary before any innovation claim.

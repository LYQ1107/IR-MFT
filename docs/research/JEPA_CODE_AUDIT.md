## GOT-JEPA

Pinned [source](https://github.com/chenshihfang/GOT/tree/5f382645ccb7331280a7bf07f3c5709d1072caf7) at `5f382645ccb7331280a7bf07f3c5709d1072caf7`; AGPL-3.0 repository. `tompnet_JEPA.py` builds DINO intermediate spatial maps and context/target classification and box-regression filters; random current-test-feature relocation supplies occlusion perturbation. `GOT_JEPA_378_pretrain.py:122–176` loads a ToMP target, freezes feature extractor/bkMLP/target head and trains context/predictor/expansion components. This pinned target is frozen, not an EMA teacher; do not attribute V-JEPA momentum mechanics to GOT. Finetuning copies learned context and predictor weights into the tracking head, then trains tracking losses. The context filter transformer embeds spatial foreground labels and box targets; these are training/known single-object tracking interfaces, not online fish GT access.

The actor's invariance/covariance loss and repeated method overrides need explicit code-level caution: earlier returns are not necessarily the active final override. Audit of this snapshot is not proof that its entire default trainer can run unchanged. We borrow the abstract separation of corrupted context and clean latent/filter targets, not AGPL model code or a claim of reproducing its SOT result. Our scientific question is repairing multi-fish accepted-history identity errors and lifecycle propagation, rather than single-target filter adaptation.

## V-JEPA2 / V-JEPA2.1

Pinned [source](https://github.com/facebookresearch/vjepa2/tree/204698b45b3712590f06245fbfba32d3be539812) at `204698b45b3712590f06245fbfba32d3be539812`; MIT code license. `app/vjepa/train.py:428–479` applies stop-gradient target encoding and normalized masked latent loss, then updates target parameters by momentum after the optimizer step. `src/models/predictor.py:174–254` combines context tokens and positional target mask tokens, sorts them, runs transformer blocks and returns target predictions. Masking alone is not proof of causal online inference.

`app/vjepa_2_1/train.py:594–705` adds hierarchical target normalization, separate target/context predictions, context loss with optional distance weighting and mixed image/video paths; its predictor has layer hierarchy and modality embeddings. The requested ViT-B256px/16frame configuration specifies large distributed image/video pretraining, not a suitable direct training recipe for our small fish bank. We implement a lightweight track-level encoder/EMA target/predictor first, supervise latent representations rather than pixels, and explicitly reject current/future context timestamps. Dense ROI/patch supervision is conditional on track-level evidence, not implied fish-part understanding.

## MOTIP

Pinned [source](https://github.com/MCG-NJU/MOTIP/tree/ffc0e905ac196a603027eca8d18fb0dff48c8bcc) at `ffc0e905ac196a603027eca8d18fb0dff48c8bcc`; Apache-2.0 code. `id_decoder.py:96–178` embeds trajectory ID vocabulary, current unknown detections and temporal information; cross-attention explicitly masks trajectory times>=current unknown time. Output vocabulary includes an extra new-ID slot. Unknown-ID training labels are returned only when training; existing trajectory ID inputs are model-assigned tokens, not a license to supply online GT identities. GET_STARTED separates DETR pretraining and full tracking training. Our first fixed-proposal study does not copy/retrain DETR or reproduce MOTIP's own-detector system; it isolates identity recovery and later, conditionally, learned lifecycle decisions.

## Implications for Fish-JEPA

A new method must include a genuinely trained context representation and separate stop-gradient target encoder with recorded EMA updates; runtime must load only student/context/predictor parameters. Current fish candidates require an explicitly consistent association space. A latent prediction objective can improve while association worsens, so we retain identity contrast/rank controls, collapse diagnostics, real accepted versus clean versus structured corrupted histories, matched ordinary GRU/Transformer capacity and output policy. Ordinary prediction is not renamed JEPA. All method contributions remain unvalidated until full controls and three-seed MOT evidence pass. No independent-paper/SOTA novelty claim follows from this audit.

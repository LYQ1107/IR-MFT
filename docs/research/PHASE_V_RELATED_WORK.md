# Phase V: 2025–2026 method comparison

Primary-source review checked2026-10-13. This is a scoped comparison, not an exhaustive novelty search. Code pins and function-level audit are in JEPA_CODE_AUDIT.md/json. Differences below describe implemented mechanisms, not validated contributions.

|Work|Documented mechanism|Phase V distinction and evidence requirement|
|---|---|---|
|[MOTIP, CVPR2025](https://openaccess.thecvf.com/content/CVPR2025/papers/Gao_Multiple_Object_Tracking_as_ID_Prediction_CVPR_2025_paper.pdf)|Uses historical trajectories and in-context IDs to predict current object IDs; association training and current-object interactions are central.|Fish-JEPA retains frozen V3 proposals and FishReID coordinates, predicts a past-context latent/prototype, and uses existing online assignment/lifecycle. It does not retrain DETR or implement MOTIP's ID-vocabulary decoder.|
|[V-JEPA2,2025](https://arxiv.org/abs/2506.09985)|Video representation prediction and subsequent action-conditioned modeling, trained at large scale.|Our supervised identity-aligned512dim track-token training uses existing features and actual accepted histories. EMA alone is borrowed machinery, not novel evidence. No web-video/model-weight download or robotic/world-understanding claim.|
|[GOT-JEPA,2026](https://arxiv.org/abs/2602.14771)|Clean/corrupted current observations supervise tracking-model prediction; OccuSolver provides object-aware occlusion reasoning.|Our student has only strictly past identity tokens; clean current/future target is teacher-only. We forecast identity embeddings rather than ToMP tracking filters, and do not implement OccuSolver. Pinned code uses a frozen target, whereas our actual lightweight teacher follows EMA.|
|[V-JEPA2.1,2026](https://arxiv.org/abs/2603.14482)|Dense visible/masked-token prediction, intermediate-layer supervision, and image/video tokenizers.|Our implementation is track-level, with training-only corresponding past-latent masks and a single latent prediction. It is not dense ROI/patch modeling, and does not establish local fish anatomy understanding. Dense exploration remains conditional.|
|[History-Aware Transformation of ReID Features,2025preprint/2026revision](https://arxiv.org/abs/2503.12562v2)|Training-free video-specific transformation from historical established trajectories using a tailored Fisher linear discriminant.|Our RIS softly reads contaminated per-track histories in fixed coordinates; Fish-JEPA learns a context encoder and target prediction. History conditioning and representation adaptation are already known; credible novelty requires independent identity recovery beyond strong ordinary models.|
|[Hierarchical Multi-Prototype Appearance Memory,2026](https://www.mdpi.com/2079-9292/15/11/2357)|Publisher abstract describes stable multi-prototype long memory and a short FIFO queue for contaminated EMA histories.|Multiple anchors/short memory are not new by themselves. Our three-prototype simple control and learned RIS are controlled local implementations, not a faithful HMP benchmark. Full publisher article fetch was rate-limited; this comparison is limited to its abstract.|
|[Online Multi-Camera3D Tracking via ID Prediction,2026preprint](https://arxiv.org/abs/2609.18363)|Adapts causal MOTIP identity prediction to fused3D observations with finite memory and newborn recovery.|Our monocular fish experiment has no calibrated3D fusion or learned newborn ID decoder. Explicit lifecycle isolation and safe recovery diagnosis are necessary controls, not evidence that general ID prediction is new.|

A new combination of past-token masking, structured identity corruption and EMA targets does not establish a paper contribution. The decisive comparison is equal data/budget/capacity against ordinary GRU/Transformer and no-EMA counterparts, with true accepted-history and full tracking gains. Until three seeds and controlled ablations support that comparison, status remains IN_PROGRESS/FAILURE_DIAGNOSED.
